# 📝 Blog Portfolio

A modern full-stack personal portfolio and blog website built with **React, Node.js, Express.js, and MongoDB**.

## ✨ Features

* 👨‍💻 About & Skills
* 💼 Projects showcase
* 📝 Dynamic blogs from MongoDB
* 📖 Individual blog articles
* 📩 Working contact form
* 📱 Responsive design

## 🛠️ Tech Stack

**Frontend:** React, Vite, CSS, Axios, React Router
**Backend:** Node.js, Express.js, MongoDB, Mongoose
**Deployment:** Vercel + Render

## 🚀 Run Locally

```bash
git clone https://github.com/kaviarasu1611/blog-portfolio.git
cd blog-portfolio

cd backend
npm install
npm start
```

In another terminal:

```bash
cd frontend
npm install
npm run dev
```
